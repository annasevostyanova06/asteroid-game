# Asteroids Game

Asteroids is a classic arcade shooter built with vanilla JavaScript, HTML Canvas, and CSS. The player controls a spaceship, destroys asteroids, and tries to achieve the highest score.

The project includes:
- Dynamic space background with parallax stars
- Ship control with keyboard (arrow keys / WASD)
- Shooting mechanics with collision detection
- Particle explosion effects
- Lives and score system
- User authentication (register, login, guest mode)
- Leaderboard with top 10 scores stored in LocalStorage
- Pixel art style with retro font and neon glow UI

Live Demo: https://annasevostyanova06.github.io/asteroid-game/
